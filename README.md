# Alexis Herencia — Portfolio

Portfolio con **doble perfil**: un switch en la barra superior cambia todo el diseño y el contenido entre

- 🎮 **Game Dev** — estilo pixel art / arcade (Unity · C#, Gameplay & UI Programmer)
- `</>` **Web Dev** — estilo moderno (Angular · Spring Boot · .NET)

Disponible en español e inglés. Sitio estático: HTML + CSS + JavaScript, sin frameworks ni build.

🔗 **https://alexishh25.github.io**

Enlaces directos: `?mode=game`, `?mode=web`, `?lang=en`.

## Editar contenido

Todo el texto (experiencia, proyectos, skills, comunidad) está en [`js/data.js`](js/data.js).

## Correr en local

```bash
npx serve .
```

## Deploy

Cada push a `main` publica el sitio en GitHub Pages con `.github/workflows/deploy.yml`.
